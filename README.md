# इतिहास MCQ प्रश्नपत्र एवं मॉक टेस्ट

CG व्याख्याता / शिक्षक भर्ती (इतिहास) के अभ्यास के लिए हिंदी MCQ सेट।

- `index.html` — ऑनलाइन मॉक टेस्ट (अभ्यास मोड, व्याख्या सहित)। GitHub Pages चालू करने पर सीधे ब्राउज़र में खुलेगा।
- `docs/` — प्रिंट योग्य Word प्रश्नपत्र (उत्तरमाला नए पृष्ठ से)।
- `data/` — टॉपिक सेट 2 और 3 के प्रश्न JSON रूप में।

नवीनतम: **गुप्त साम्राज्य, जैन एवं बौद्ध धर्म — टॉपिक सेट 3** (100 प्रश्न; 30 सरल / 50 मध्यम / 20 कठिन; उत्तर A/B/C/D प्रत्येक 25)।

> ये अभ्यास-पत्र हैं, पिछले वर्षों के आधिकारिक प्रश्नपत्र नहीं।
